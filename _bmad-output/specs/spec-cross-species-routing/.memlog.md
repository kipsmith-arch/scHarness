- (direction) Q3 回答:覆盖率高时(目标物种在 KG 中 cell type 覆盖充分)也并行跑 Ensembl 同源映射,最后融合单物种+跨物种路径,取最准而非最快。
- (direction) Q4 回答:ortholog_map 同 target_species+reference_species 组合复用历史映射(species-level 缓存),--force-refresh 强制重打。
- (direction) Q5 回答:Ensembl 不可用时(网络挂/限速)降级为跳过跨物种路径,退回纯单物种路径,run_log.jsonl 记录 warning,不阻断 pipeline。
- (note) Neo4j 实测覆盖:Plant 18 种(arabidopsis_thaliana 21299 genes/195 cell types/141497 edges,水稻 25397 genes,zma 22669 等),Animal 11 种(Human 10187 genes/348 cell types,Mus musculus 7214 等)。arabidopsis_thaliana 自身覆盖极其充分,跨物种在拟南芥数据集上不应触发主流路径但应并行验证。
- (note) Ensembl Compara REST 实测验证:GET /homology/symbol/{species}/{symbol}?type=orthologues&target_species={ref} 返回 target.id/target.species/perc_id/perc_pos/type(one2one/one2many),无需传序列。Ensembl Plants 在独立域名 rest.plants.ensembl.org(本机 DNS 不通,但生产一般能访问)。
- (note) KG 物种命名混用:Plant 全部小写下划线(arabidopsis_thaliana),Animal 大写带空格(Human/Mus musculus)。step2_ortholog 与 step3_kg 都需物种名规范化映射表,kg-schema.md 已记录此现象。
- (capability) CAP-1 precheck: skill 可在 KG 上查询目标物种的 cell type 覆盖率(genes_with_ct_for_target_species),根据覆盖率返回 recommended_strategy: high(>=500) / medium(50-500) / low(<50) 与 recommended_reference_species(同 species_type 下 cell type 覆盖最高的若干物种,按亲缘距离加权重排序)。0 h5ad 加载,纯 Neo4j 查询。
- (capability) CAP-6 references 文档扩展: sop.md 新增 SOP-2.5(跨物种路由预检)和扩展 SOP-3(预检→同源映射→organ 对齐→融合);traps.md 新增跨物种专项陷阱(物种命名格式、Ensembl 限速、一对多、层级过度传播、扩张家族、参考物种覆盖不足等);metrics.md 新增 ortholog_*、n_direct_hits、n_ortholog_hits、recommended_strategy 字段的 LLM 解读;kg-schema.md 物种命名章节补 Ensembl 端点路由说明。
- (capability) CAP-4 LLM 静默路由决策: SKILL.md 新增 cross_species_routing(session 级)决策点,LLM 读完 precheck 报告后判断 routing_accept(采用推荐策略) / routing_force_single(强制单物种路径) / routing_force_cross(强制跨物种路径,即便 KG 覆盖高) / routing_multi_reference(显式多参考物种)。该决策点后 LLM 在 SOP-3 内根据决策结果选择调 step2_ortholog + step3_kg(跨物种路径)或直接调 step3_kg(单物种路径)。
- (capability) CAP-5 SKILL.md 触发扩展: cell-annotation skill 的 description 触发条件扩展,覆盖跨物种场景(注释非模式生物数据/用模式生物参考/目标物种在 KG 中覆盖不足等)。原 description 不变,只新增触发短语。
- (capability) CAP-3 step3_kg 跨物种融合: skill 可在 step3_kg query 中同时跑两条路径(marker 直接命中 + marker→ortholog→参考物种基因命中),候选 cell_type 聚合时保留 source_species 与 source_path(direct/ortholog)字段;LLM 决策视图暴露 n_direct_hits/n_ortholog_hits/n_mixed_hits 用于候选 gap 判断。Ensembl 不可用时降级为只跑直接路径,run_log.jsonl 记 warning。
- (capability) CAP-2 ortholog_map: skill 可调用 Ensembl Compara REST 把目标物种 marker 映射到参考物种 ortholog(symbol-based,无需蛋白序列)。支持多参考物种、单/批 POST + GET 兜底、按 species_type 自动选 Ensembl 端点(Plants→rest.plants.ensembl.org,其它→rest.ensembl.org)、一对多过滤(--max-hits-per-gene)、相似度阈值(--min-identity)。同 target_species+reference_species 组合复用 species-level 缓存,--force-refresh 强制重打。0 h5ad 加载。
- (constraint) Constraint-1: 一个子命令 = 一次 h5ad 加载(既有架构铁律)。step3_kg_precheck 与 step2_ortholog 必须纯 JSON / 外部 API,严禁碰 h5ad。
