# 跨物种单细胞注释手册

---

# 第一部分　跨物种单细胞注释方案流程

跨物种单细胞注释的本质问题：**目标物种（非模式生物）没有参考图谱，所以要"借"模式物种的注释知识**。下面是成熟专家的标准流程。

## 一、先搞清楚你有什么、要什么

- **目标物种**：你要注释的是谁（比如竹子、某种鱼）
- **参考物种**：注释知识丰富的模式生物（人类、小鼠、拟南芥、水稻、斑马鱼等）
- **输入**：scRNA-seq 数据，已经做过聚类（每个 cluster 是一群表达相似的细胞）
- **目标**：给每个 cluster 贴上"这是什么细胞"的标签（如 T 细胞、导管细胞）

关键原则：**亲缘关系越近越好**。注释人和猩猩很容易，注释人和细菌几乎不可能。如果目标物种亲缘太远，就多选几个参考物种，用一个近缘的保准确性 + 一个远的保覆盖。**本 skill 最多 3 个参考物种**，由注释者（LLM）按亲缘从静态名录点名，工具不打分推荐。动植物不要混库。

## 二、核心流程（6 步）

### 预备概念（先搞懂这几个词再往下看）

- **scRNA-seq（单细胞 RNA 测序）**：测每个细胞里哪些基因在表达、表达多少，输出"细胞 × 基因"的表达矩阵（每格是一个数字，表示某细胞里某基因测到了几条 mRNA）。
- **聚类（clustering）**：把表达模式相似的细胞归到一起，每一组叫一个 cluster。理想情况下一个 cluster ≈ 一种细胞。
- **细胞类型（cell type）**：功能/身份不同的细胞类别，如 T 细胞、导管细胞、神经元。每种细胞有一组"特异高表达"的基因作为身份标签。
- **marker 基因（标记基因）**：在某一种细胞里高表达、在其他细胞里低表达/不表达的基因，是这个细胞类型的"身份证"。例：CD3D 是 T 细胞的 marker。
- **同源基因（ortholog / paralog）**：不同物种里由共同祖先基因演化来的基因，相当于"同一个基因"在不同物种里的版本。一对一是 ortholog；一个目标基因对应参考物种里多个基因（复制副本）是 paralog。
- **DE（差异表达分析）**：统计检验哪些基因在某 cluster 里的表达显著高于其他 cluster，输出按特异性排序的基因列表。
- **pct1 / pct2**：DE 输出的两个关键指标。pct1 = 该 marker 在本 cluster 多少比例细胞里表达；pct2 = 在其他 cluster 多少比例细胞里表达。好 marker 应该 pct1 高、pct2 低。
- **知识图谱（KG）**：结构化的"基因—细胞类型—组织"数据库，带层级关系（如 T 细胞 ⊂ 淋巴细胞 ⊂ 白细胞 ⊂ 免疫细胞）。

### 第 1 步：找目标物种自己的 marker 基因

**做什么**：对每个 cluster 做 DE，找出"这个 cluster 特异高表达"的基因。

**为什么**：marker 基因是 cluster 的身份标签，后面所有跨物种映射都基于这些基因。这一步纯靠目标物种自己的数据，不需要参考物种。

**具体操作**：
1. 对每个 cluster，把它当"目标组"，其他所有 cluster 当"背景组"，跑 DE。
2. DE 输出按特异性排序的基因列表（top marker）。
3. 每个 cluster 取 top 30 左右作为它的 marker 基因集。
4. 过滤掉管家基因（核糖体 RPL/RPS、线粒体 MT-、组蛋白、应激 HSP——它们在所有细胞都表达，不是身份标签）。
5. 过滤掉表达比例太低的（要求 marker 在 cluster 内 >50% 细胞表达，即 pct1 >0.5）。

**输出**：每个 cluster 一个 marker 基因列表（约 30 个）。

### 第 2 步：跨物种基因映射（最关键的一步）

**做什么**：把目标物种的每个 marker 基因，对应到参考物种里的同源基因。

**为什么**：你的目标物种 marker 没有已知细胞类型注释，但参考物种的同源基因有。建立这个对应关系，才能"借"参考物种的注释知识。

**关键点**：
- 用**蛋白序列**比对（不是核酸）——蛋白序列比核酸更保守，跨物种相似度更高，核酸会因为同义突变等迅速衰减。
- 一个目标基因可能命中参考物种好几个基因（一对多，paralog），这种多拷贝家族（如嗅觉受体、免疫基因）要降权或过滤，否则会引入噪声。

**具体操作**：
1. 取目标物种每个 **marker** 基因的蛋白序列（不要拿整份表达矩阵的每个基因去比）。
2. 对参考物种的蛋白库做序列比对，找最相似的命中。必须用蛋白，不用核酸。
3. **一对多在映射步收，不要留给图谱**：每个参考物种只留 best hit 1 条。不因一对多丢掉整条 DEG。用了多个参考物种时，每个物种的那一条都留下（跨物种印证）。
4. 图谱只回答「这个参考基因标记什么细胞」，分不清 ortholog / paralog；图谱边上的 confidence 也不是比对分数。

**本 skill 的落地（与上面一般做法对齐的部分 / 刻意不做的部分）**：
- Subject 库：预构建的 27 物种 BLASTDB，部署后缺库则自动下载；skill 包里不带二进制。
- Query：用户提供 FASTA。先按 h5ad 基因 ID（`var_snapshot.csv`）过滤，再与 marker 求交。skill 不提供 query 序列。
- 后端：默认仍可用 Ensembl Compara（不传序列）。`blastp` 故障时同一组参考物种改道 Ensembl。
- **第一版不做 reciprocal best hit**：没有目标物种全蛋白库，只有用户的 query FASTA。手册后文仍把 RBH 当作一般专家建议，不是本 skill 的实现项。
- 理不理想由注释者判断，不设 hit_rate / 空候选比例等备用阈值。

**输出**：每个目标 marker 基因 → 每个所用参考物种至多 1 个同源基因。

完整规范：`_bmad-output/specs/spec-blastp-homology/SPEC.md`。

### 第 3 步：获取参考物种的"基因→细胞类型"知识

**做什么**：从参考物种的图谱/数据库里查出：哪些基因标记哪些细胞类型。

**为什么**：上一步把目标 marker 连到了参考物种基因，现在要知道这些参考物种基因分别标记什么细胞类型——这就是你要"借"的注释知识。

**来源**：
- marker 数据库（如 PanglaoDB、CellMarker，收录文献里验证过的 marker）
- 论文里的 marker list
- 结构化的知识图谱（KG：基因—细胞类型—组织，带层级关系）

**具体操作**：
1. 选定 organ（器官/组织）——必须和你的数据来源 organ 对齐（用肝脏的 KG 查叶片数据必然错）。
2. 在 KG 里按 organ 过滤，只保留该 organ 的基因—细胞类型关系。
3. 把第 2 步得到的参考物种同源基因列表拿去 KG 查，每个基因标记哪些细胞类型。

**输出**：每个参考物种同源基因 → 它标记的细胞类型列表（已按 organ 过滤）。

### 第 4 步：判断每个 cluster 是什么细胞

**做什么**：综合判断每个 cluster 最像什么细胞类型。

**为什么**：到此你有了：cluster 的 marker → 同源到参考物种 → 参考物种基因标记的细胞类型。要把这些信息汇总成一个判断。

**判断逻辑**：
- 多个 marker 一致指向同一类型 → 大概率就是这种细胞
- 序列相似度高的命中更可信（弱相似可能是偶然撞上的）
- 一个 cluster 通常会冒出 1~几个候选类型

**具体操作**：
1. 对每个 cluster，汇总它的所有 marker 经同源映射后命中的细胞类型。
2. 看哪个细胞类型被最多 marker 指向（且命中相似度高）→ 第一候选。
3. 看第二多指向的类型 → 第二候选。
4. 第一候选明显领先 → 直接定。
5. 第一和第二候选势均力敌 → 标记为模糊，进第 5 步 refine。

   怎么算"势均力敌"（满足任一即算模糊，该 refine）：
   - **支持 marker 数接近**：第一候选被 8 个 marker 指向，第二候选 7 个——数量差不多。
   - **命中相似度接近**：第一候选的 hit 平均相似度 70%，第二候选 68%——强弱差不多。
   - **双方 canonical marker 都表达**：查 T 细胞的 CD3D 和 B 细胞的 CD79A，都在该 cluster 高表达——生物学上就是模糊（可能是双细胞、过渡态、或未分化的祖细胞）。

   怎么算"明显领先"（直接定，不用 refine）：
   - 第一候选支持 marker 远多于第二（如 15 vs 3）。
   - 只有第一候选的 canonical marker 高表达，第二候选的不表达。

**输出**：每个 cluster 一个候选细胞类型（带置信度）。

### 第 5 步：处理模糊和缺失

**做什么**：对模糊的 cluster 细化，对没命中的 cluster 标注 unknown。

**为什么**：模糊的 cluster 可能混了多种细胞，细化能让亚型浮现；没命中的 cluster 可能是物种特异细胞类型，参考物种里根本没有，硬贴标签只会错。

**具体操作**：
1. **模糊 cluster**（第一第二候选势均力敌）：对这个 cluster 内部重新聚类（refine），分成更小的子 cluster，对子 cluster 重新跑 DE 拿子 cluster 特异 marker，再走第 2-4 步。注意 refine 前要求 cluster 细胞数 ≥100，否则 DE 没检验力，分出来的是噪声。

   **怎么检验 refine 成功（确实分出更纯的亚型）**：
   - 每个子 cluster 现在第一候选明显领先（不再纠缠不清——按第 4 步的判断标准）。
   - 子 cluster 之间 DE 出来的 marker 各自特异、不重叠（每个子 cluster 有自己独占的高表达基因）。
   - 子 cluster 注释出的类型落在父 cluster 原来的候选范围内（如父在 T/B 之间纠结，子分出 T 和 B——合理）。

   **怎么发现 refine 失败**：
   - **没分纯**：子 cluster 第一第二候选仍然纠缠不清 → refine 没起作用，退回父级标签或直接标 ambiguous。
   - **分错了（和父级候选完全无关）**：子 cluster 注释出的类型跟父 cluster 原候选对不上（如父在 T/B 间纠结，子却分出"神经元""成纤维细胞"）→ 分裂是被批次/质量差异驱动的，不是生物学亚型；丢弃这次 refine，回头查该 cluster 的样本组成和 QC（多半是某个样本/低质量细胞主导了分裂）。
   - **分得太碎**：子 cluster 细胞数都很少（如各 10 几个）→ DE 没检验力，结果不可信（见 6.4）。
2. **没命中的 cluster**：不要硬贴标签。把它的 marker 集中分析——看 unknown cluster 之间彼此的 marker 是否也不重叠；如果不重叠，它们可能是各自独立的物种特异细胞类型，应分别标注"unknown type A/B"，而不是统称 unknown。

**输出**：模糊 cluster 被细分成更纯的亚型（按上述标准检验过，失败的退回父级或标 ambiguous）；物种特异 cluster 诚实标 unknown。

### 第 6 步：验证

**做什么**：用独立证据核对注释结果。

**为什么**：跨物种注释本质是预测，不是确证。不核对就当 ground truth 用，错的会被下游分析放大。

**具体操作**：
1. 对每个注释，附 top 3 canonical marker 在该 cluster 的表达分布（violin/heatmap），让标签可追溯。
2. 拿注释出的细胞类型，去查该类型的经典 marker（如 T 细胞的 CD3D/LCK）在你的 cluster 里是否真的高表达——不表达就是错的。
3. 如果该物种有少量已注释数据，做交叉验证。
4. 明确标置信度（high/medium/low）：第一候选明显领先 + marker 数 >15 = high；否则 medium/low。下游分析对 low 单独看，不和 high 混一起。

**输出**：每个 cluster 一个带置信度的细胞类型标签 + 独立 marker 表达证据。

完全无参考时，注释结果的可信度取决于亲缘距离和 marker 数量。

## 三、专家会告诉你的几个"潜规则"

1. **亲缘距离决定天花板**。同属物种注释质量高；跨纲跨门就要降低期望，并明确标注"低置信度"。
2. **一对多同源是最大的噪声源**。宁可丢掉多拷贝家族的基因，也别让它们稀释信号。
3. **器官/组织必须对齐**。用肝脏的 marker 去注释叶片数据必然出错——参考物种的知识图谱要按 organ 过滤。
4. **知识图谱的层级结构很有用**。"T 细胞"查不到时，往上一层"淋巴细胞"往往能查到，再往下细分。
5. **物种特异细胞类型无法救**。参考物种里压根没有的细胞类型，任何注释方法都注释不出来，要诚实标注 unknown 而不是编一个。
6. **多个参考物种 > 单个**。一个近缘 + 一个远缘但图谱丰富的，比只用一个更稳。

# 第二部分　跨物种/非模式物种单细胞注释常见坑

按流程顺序排列，从数据预处理到最终验证。每条都是真实项目里反复出现的、不是教科书会明说的那种坑。

## 0. 数据预处理阶段

### 0.1 用错基因组注释版本
非模式物种的基因组/注释文件常有多个版本（v1 草图、v2 修正版、社区修订版）。表达矩阵用 v1 的注释数基因，后续序列比对用 v2 的蛋白序列 → **基因 ID 对不上**，整条 pipeline 静默失败，注释全是 unknown 但不报错。
**对策**：记下表达矩阵和蛋白序列用的基因组/注释版本号，确保同一个版本贯穿全程。

### 0.2 基因 ID 不统一
同一个物种，不同数据库用不同的 ID 体系（如 Ensembl ID、NCBI Gene ID、自己组装的内部 ID）。表达矩阵用一种，序列比对数据库/知识图谱用另一种 → 映射时丢一半基因。
**对策**：建一个统一的 ID mapping 表，在最早一步把所有 ID 转成同一个体系（推荐用 UniProt accession 或 NCBI Gene ID，跨库兼容性最好）。

### 0.3 在归一化数据上跑 DE
DE 分析应该在原始 counts 上跑。如果在 log 归一化后的数据上跑 DE，logfc 范围被压缩，marker 权重失真 → 跨物种映射时强表达和弱表达分不开。
**对策**：确保 DE 模型输入是原始 counts；归一化数据仅用于可视化/聚类，不进入 DE。

### 0.4 高变基因选拔把跨样本差异基因当噪声砍掉
按方差选高变基因（HVG）时，非模式物种数据常带强烈的批次效应（不同个体、不同测序批次），批次差异基因方差最高 → 被选为 HVG → 实际是噪声。
**对策**：先做批次校正再用基于原始 counts 的 HVG 选拔，或分批选 HVG。

### 0.5 线粒体/叶绿体基因过滤阈值照搬
人和小鼠常用线粒体基因占比 < 20% 过滤低质量细胞。植物有叶绿体，某些正常细胞叶绿体基因占比就高；某些组织（肝脏）线粒体天然就高。照搬阈值会把真实细胞当死细胞过滤掉。
**对策**：先画线粒体/叶绿体基因占比的分布图，按组织类型和物种重新定阈值，别用默认值。

### 0.6 双细胞（doublet）检测参数不适配
预期 doublet 率默认按 1%/1000 cells 算，来源于人类/小鼠 10x 经验。非模式物种、不同组织、不同解离方法下 doublet 率差异很大。
**对策**：根据实际解离 protocol 和测序深度调预期 doublet 率；植物细胞因细胞壁解离困难、多核细胞多，doublet 模式跟动物不一样，要单独验证。

### 0.7 归一化方法对稀疏数据不适配
非模式物种很多细胞类型捕获效率低、数据稀疏，常规 log 归一化让低表达基因全变 0 → DE 检不出来。
**对策**：稀疏数据用专门针对低计数的归一化方法（这类方法内部仍基于原始 counts 建模，如负二项回归，不是简单 log 转换），比经典 log 归一化在低计数区表现好；或先按 cluster 合并 pseudo-bulk 再做 DE，单细胞层 DE 对稀疏数据噪声太大。关键原则不变：DE 必须基于原始 counts 或基于原始 counts 的统计模型，不要在 log 归一化后的数据上直接跑 DE（见 0.3）。

## 1. 聚类阶段

### 1.1 分辨率(resolution)一刀切
聚类分辨率在人和小鼠上是经验值。非模式物种细胞类型组成不同（比如某种组织 90% 是一种细胞），用同样分辨率会要么过碎（一种细胞被切成 10 个 cluster）要么过合（多种细胞合进一个 cluster）。
**对策**：跑多个分辨率，看 cluster 数随分辨率的拐点，选拐点附近的值；或用 cluster tree 可视化稳定性。

### 1.2 把批次效应当细胞类型
没做批次校正就聚类，结果 cluster 几乎完全按样本/批次分开，每个 cluster 里其实是同一种细胞的多个批次副本。注释时这些 cluster 都指向同一类型，但看起来"cluster 数很多 = 类型丰富"。
**对策**：先看每个 cluster 的样本组成，如果 cluster 几乎 100% 单一来源 → 强批次信号，先校正再聚类。

### 1.3 聚类太粗导致注释失败
为了"干净"用了很低的分辨率，结果一个 cluster 里混了 3 种细胞 → DE 出来的 marker 是三种细胞 marker 的平均，没有特异 marker → 跨物种映射全空。
**对策**：宁可分细一点（分辨率偏高），注释完再合并同类型 cluster，比反过来"分粗了再想拆"容易。注释阶段发现某 cluster 多候选势均力敌 → 这就是该 refine 的信号。

### 1.4 用错聚类特征
对全部 HVG 聚类，但某些细胞类型的关键差异只在少数基因上（如免疫细胞的抗原受体）。这些基因没进 HVG 池 → T/B 细胞被聚到一起。
**对策**：在已知关键 marker 基因上强制保留（手动加入 HVG 列表），或对特定组织用该组织已知的 marker list 引导聚类。

### 1.5 UMAP 可视化误导
UMAP 是可视化不是分析。UMAP 上"分得很开"不等于聚类上分开；两个 cluster 在 UMAP 上靠近不等于相似。注释决策要基于 DE/统计，不是 UMAP 图。
**对策**：UMAP 只用来汇报结果；判断 cluster 是否该合并/拆分，看 DE marker 和轮廓系数。

## 2. Marker 基因阶段

### 2.1 DE 用错对比组
DE 默认是每个 cluster vs 其他所有 cluster。如果某细胞类型占 80%，它的 marker 在 vs-all 里几乎检不出（到处都是）；稀有细胞类型反而 marker 一堆。
**对策**：对大群用 vs-rest 没问题；稀有类型用 one-vs-one（只对比最相似的另一个 cluster），或 pseudo-bulk 差异分析更稳。

### 2.2 marker 数量太少/太多
marker 数经验值在 30 左右。基因数太少（如 10）→ 跨物种映射后命中不够，注释不出来；太多（如 200）→ 噪声 marker 稀释信号，注释全模糊。
**对策**：先按 cluster 大小定 marker 数（小 cluster 用少一点，因为 DE 检验力弱），或用动态阈值（logfc 阈值 + 最少 15 个 marker 兜底）。

### 2.3 把管家基因当 marker
核糖体蛋白、线粒体基因、组蛋白在所有细胞都表达，DE 偶尔因为某 cluster 细胞数少/质量差而看起来"高表达" → 被选为 marker → 跨物种映射必然命中（管家基因最保守）→ 注释出"增殖细胞""代谢细胞"这种无意义结果。
**对策**：DE 前显式过滤已知管家基因列表（核糖体 RPL/RPS、线粒体 MT-、组蛋白、应激 HSP）；另外 pct1 >0.9 的"marker"几乎肯定是管家基因（到处都表达），一并丢。

### 2.4 不看 marker 在 cluster 内的表达比例
某 marker 在该 cluster 只有 30% 细胞表达（pct1=0.3），在其他 cluster 5% 细胞表达（pct2=0.05）→ 看起来差异大，其实只是少数细胞拉高的，不是这个 cluster 的稳定标签。
**对策**：marker 要同时满足两个条件——(1) 在 cluster 内大多数细胞表达（pct1 在 0.5-0.9 之间；<0.5 表达太低不稳定，>0.9 多半是管家基因到处都表达）；(2) 明显高于其他 cluster（pct1 - pct2 按分层标准：<0.1 直接丢，0.1-0.25 灰色地带，>0.25 才算稳定 marker）。比纯按 p 值过滤更稳。

### 2.5 假 marker：批次/质量基因
某 cluster 看起来有强 marker，实际是因为这 cluster 全是某个样本/低质量细胞，marker 反映的是批次/质量差异不是细胞类型。
**对策**：检查 top marker 是否在多个样本/多个细胞中都特异；如果 marker 在所有 cluster 都"特异"但样本集中 → 是批次 marker，丢弃。

## 3. 跨物种映射阶段

### 3.1 序列比对数据库选错物种
用人的蛋白库去注释植物，或者用小鼠库注释鱼 → 同源关系极远，命中几乎全是低相似度的"碰巧相似"。
**对策**：参考物种选亲缘最近的模式物种；如果非模式物种是植物，首选拟南芥/水稻，不是人和小鼠。

### 3.2 一对多不加处理
目标基因 A 命中参考物种 A1/A2/A3，三个标记不同细胞类型 → 信号分散。详见前述"多拷贝家族"讨论。
**对策**：每个参考物种只留 best hit；跨物种的 hit 都留。不要把 paralog 列表丢给图谱去「用 confidence 筛」。本 skill 不因一对多丢掉整条 DEG。

### 3.3 序列比对阈值照搬
默认阈值对同属够、对跨目太宽。阈值不对 → 要么噪声 hit 一堆，要么真同源被砍光。
**对策**：按亲缘距离调：同属相似度高、覆盖完整即可；跨目相似度阈值收紧；跨纲再严。看比对结果的相似度分布拐点定阈值。

### 3.4 用核酸序列做比对
跨物种用核酸比对几乎没意义——同义突变、UTR 差异让相似度迅速衰减。必须用蛋白序列。
**对策**：永远用蛋白序列比对；如果只有核酸，先翻译成蛋白再比对。

### 3.5 漏掉"反向最佳命中"验证
A → 参考物种 B 是 best hit，但 B → 目标物种的 best hit 是 C 不是 A → A 和 B 不是真正的 ortholog，只是单向相似。
**对策（一般）**：要求 reciprocal best hit（RBB）才认作 ortholog；或至少看 B 的 best hit 是不是落在 A 附近（前 3 名）。
**本 skill**：第一版不做 RBB（用户只提供 query FASTA，没有目标物种全蛋白库）。发现单向相似时由注释者降权或换参考物种，不在 3b 用阈值自动丢。

### 3.6 基因家族在目标物种扩张未识别
参考物种里某基因是单拷贝，目标物种里扩张成多个副本。目标 marker 是扩张家族的一员，比对到参考的单拷贝 → 注释按参考的功能走，但目标基因可能已分化了底物特异性/功能。
**对策**：先对目标物种自己做基因家族聚类，识别扩张家族，这类基因注释降一档置信度；不要把扩张家族的注释当成强证据。

## 4. 知识图谱/参考注释阶段

### 4.1 organ 不对齐
用肝脏的知识图谱去注释叶片数据 → 肝脏 marker 基因在叶片里不存在或表达模式完全不同，注释必然错。
**对策**：必须按 organ 过滤 KG；如果不确定 organ，宁可不过滤也别乱选。

### 4.2 参考物种图谱覆盖不全
模式物种也不是所有组织/所有细胞类型都注释全了。拟南芥根系注释好，叶片就少；小鼠免疫好，神经系统就粗。
**对策**：选参考物种时查它在该 organ 的注释完整度；多个参考物种互补——一个注释好但亲缘远的 + 一个亲缘近但注释差的。

### 4.3 细胞类型命名层级混乱
参考图谱里 "T cell" 和 "T lymphocyte" 是同一个东西但写法不同；"NK cell" 在人和小鼠里都是 NK，但在某些鱼里叫 "NK-like cell"。
**对策**：建一个 cell type 标准化字典（ontology，如 CL:000xxxx），所有注释先映射到标准名再比较。

### 4.4 知识图谱过时
图谱是 2 年前建的，那时免疫细胞只有 5 个亚型；现在已经分到 20 个亚型。用旧图谱注释，新亚型全被注释成"parent type"。
**对策**：定期更新 KG；如果用云端 KG，确认版本日期；如果自建，记录 KG 构建日期。

### 4.5 物种特异细胞类型无参考
目标物种有种特有的细胞类型（如植物特有的筛管分子、节肢动物特有的血细胞亚型），参考物种根本没有 → 注释必然 unknown。但 unknown 不是失败，是真实情况。
**对策**：unknown 集中分析——这些 cluster 的 marker 看是否形成自己的一组（即物种特异类型）；不要硬贴一个参考物种类型。

## 5. 注释判断阶段

### 5.1 把"弱命中多"当成"信号强"
10 个 marker 都弱命中"成纤维细胞"，1 个 marker 强命中"上皮细胞"，如果只数命中数 → 成纤维细胞胜出。但弱命中可能是多拷贝家族撞上的噪声，1 个强命中往往比 10 个弱命中更可信。
**对策**：判断时相似度高的命中优先；强弱差异大时，强命中的一票胜过一堆弱命中。

### 5.2 第一候选和第二候选势均力敌就贸然下结论
某 cluster 最像 T 细胞，但第二像的 B 细胞紧随其后、差距很小 → 直接报"T 细胞"是错的，该 refine 细看。
**对策**：第一候选要明显领先第二候选才能直接定（"明显"= 肉眼能看出差距，不是纠缠不清）；纠缠不清的就 refine 或报"ambiguous"。

### 5.3 标准定太严全 unknown
可信标准定太高，多数 cluster 都达不到 → 全打 unknown → 看起来"注释失败"。
**对策**：unknown 率分层判断——`>30%` 开始警惕（见自检清单）；`>40%` 且多个参考物种都试过仍如此 → 多半是参考物种图谱覆盖不全（见 4.2）；`>50%` 才说明标准太严。标准太严就把可信标准放宽一档，配合保守模式（不沿图谱层级往上传播）而不是激进传播模式；不要为追求"每个 cluster 都有标签"而无限放宽。

### 5.4 沿图谱层级过度传播
知识图谱层级深时，激进传播会把一个弱信号沿层级传得很远，从"T 细胞"传到"白细胞"再传到"免疫细胞"——每个 cluster 都被推到很高层级，看似都注释了，实际粒度太粗，没意义。
**对策**：传播要设门槛——信号弱到一定程度就不再往上传播，不让它一路传到根；适时切换到不传播模式（只认直接命中的类型，不往上推）。

## 6. 细化(refine)阶段

### 6.1 refine 触发条件不对
要么对所有 cluster 都 refine（多数 cluster 第一候选碾压，根本不该 refine），要么只对第一候选胜出的 refine（漏掉真正模糊的）。
**对策**：触发条件应该是"第一候选和第二候选势均力敌"——纠缠不清才是真正模糊的、该 refine 的；第一候选碾压就没必要 refine。

### 6.2 refine 用的 marker 还是父 cluster 的
父 cluster 的 marker 在子 cluster 间已经不特异了（因为它定义的是整个父 cluster），用它再分 → 分不开。
**对策**：refine 时对子 cluster 重新做 DE（在父 cluster 范围内），用子 cluster 特异 marker 再映射。

### 6.3 Moran's I 阈值照搬
空间自相关过滤阈值（Moran's I）对组织空间结构敏感。某些组织细胞排列规则，I 值天然高；某些组织细胞离散，I 值天然低。照搬阈值会把真 marker 过滤掉或留下噪声。
**对策**：先看 Moran's I 分布，按分布尾部定阈值；阈值范围 [-1, 1] 越接近 1 越严，跨物种保守起见从 0.5 开始调。

### 6.4 refine 后细胞数太少无统计意义
一个 cluster 50 个细胞，refine 想分成 3 个亚型 → 每个亚型十几个细胞，DE 几乎没检验力，分出来的亚型是噪声。
**对策**：refine 前要求 cluster 至少 N 个细胞（如 100+），少于阈值的不 refine 直接报"细胞数不足，无法细分"。

## 7. 验证与汇报阶段

### 7.1 拿不出任何独立证据
注释完只给出 cell type 标签，没有独立 marker 表达证据 → 读者无法判断对错。
**对策**：每个注释附带 top 3 marker 在该 cluster 的表达分布（violin/heatmap），让标签可追溯；unknown cluster 单独汇报。

### 7.2 把"注释结果"当 ground truth
跨物种注释本质是**预测**，不是**确证**（是按同源关系把参考物种的标签"借"过来的推断，不是实验验证过的事实）。但下游分析直接当已知细胞类型用，错的注释被放大。
**对策**：明确标注置信度（high/medium/low），下游分析对 low confidence 单独看，别和 high 混一起。

### 7.3 不报告参考物种依赖性
"这个细胞被注释为 X" 隐含"基于物种 Y 的图谱"。换参考物种注释可能变。
**对策**：注释结果里记录用的是哪个/哪些参考物种、KG 版本、比对阈值——可复现性来自这些元信息，不是只来自结果标签。

### 7.4 只画 UMAP 不画质控
UMAP 看起来"分群清晰、注释漂亮"，但低质量细胞/双细胞没清干净时，UMAP 也可能好看——因为噪声也分开了。
**对策**：汇报时必带 QC 图（基因数/counts/线粒体占比分布、doublet 率、细胞数 per cluster），不只是 UMAP。

## 速查表：症状 → 可能的原因 → 快速排查

| 症状 | 最可能的原因 | 第一步排查 |
|---|---|---|
| 全部 cluster 都 unknown | 同源映射没命中 / organ 选错 / 阈值太严 | 看命中率；查 organ 是否对齐 |
| 所有 cluster 注释成同一种细胞 | 管家基因当 marker / 批次效应 | 看 top marker 是否管家基因；看 cluster 样本组成 |
| 注释粒度太粗（都到"免疫细胞"） | 沿层级过度传播 / KG 层级太深 | 切保守模式（不传播）；提高传播门槛 |
| 注释粒度太细（一种细胞分 10 类） | 聚类分辨率太高 / refine 太激进 | 降分辨率；检查 refine 触发条件 |
| 少数 cluster 注释很离谱 | 这几个 cluster 是批次/质量产物 | 看 cluster 的样本/质量分布 |
| 重跑结果变了 | 复用旧中间结果 / 参数没生效 | 删中间结果重跑；核对参数 |
| 跑了几天没结果 | 同源映射卡住 / KG 挂 | 查同源映射是否完成；查 KG 是否返回数据 |

# 第三部分　怎么在实践中识别这些坑

坑的列表没用——关键是怎么在跑流水线时**及时发现**自己踩中了。大部分坑不会报错，只会悄悄给你一个看起来"有结果"但错误或低质量的注释。下面按流水线阶段给出"信号 → 排查动作"清单。

核心原则：**不要看注释结果好不好看，要看中间产物**。注释标签是终点，判断对错必须看 marker、同源命中、KG 查询这些上游产物——它们留下了"这个结论怎么来的"的痕迹。

## 0. 数据预处理阶段

### 怎么知道基因 ID/版本对错了
- **信号**：同源命中数异常低（<10% marker 命中），但物种亲缘并不远。
- **排查**：取 10 个 marker 基因，手动去参考物种的数据库搜它们的 ID，看是否真的查不到——如果手动能查到但 pipeline 查不到，ID 系统不匹配。
- **快速验证**：在表达矩阵和蛋白序列里数重叠基因数，如果重叠率 <50%，ID 系统肯定不一致。

### 怎么知道在归一化数据上跑了 DE
- **信号**：DE 报错找不到原始 counts，或 logfc 最大值都很小（<2）。
- **排查**：确认 DE 输入是原始 counts 还是归一化数据。如果在归一化数据上跑，marker 权重会失真（logfc 范围压缩）。
- **看 DE 结果**：logfc 范围异常窄、强表达和弱表达分不开，基本就是在归一化数据上跑的。

### 怎么知道 HVG 选拔被批次效应带偏
- **信号**：聚类后 UMAP 上按样本/批次分开，而不是按细胞类型分开。
- **排查**：UMAP 上色样本来源，如果颜色块和 cluster 块高度重合 → 批次主导。
- **看 HVG**：top HVG 里如果大量是核糖体/线粒体/应激基因（这些是批次敏感的管家基因），批次信号已经混进 HVG 池。

### 怎么知道线粒体/叶绿体阈值定错
- **信号**：过滤后细胞数大幅减少（>50%），或某些组织本该有的细胞类型消失。
- **排查**：过滤前后画线粒体基因占比分布，看阈值是否切在真实细胞群的尾部而不是中间。植物要看叶绿体基因占比，某些绿色组织正常就高。
- **反向验证**：被过滤掉的细胞里，是否包含已知该有的细胞类型 marker 阳性细胞——如果有，阈值太严。

### 怎么知道 doublet 检测参数错
- **信号**：被标记为 doublet 的细胞集中在某些细胞类型（如免疫细胞天然表达更高 → 被误判 doublet）。
- **排查**：看 doublet 评分在 cluster 间的分布，如果某个 cluster doublet 率异常高（>10%），可能不是真 doublet 而是该类型基因表达高。
- **抽查**：随机取 5 个"doublet"，看它们表达的 marker 是否真的像两种细胞的混合，还是单一类型——后者是误杀。

### 怎么知道归一化方法不适配稀疏数据
- **信号**：DE 出来的 marker 几乎全是 0 表达（pct1 < 0.1），但 p 值显著——典型低计数假阳性。
- **排查**：看 marker 的 pct1 分布，中位数 <0.2 说明数据太稀疏，单细胞 DE 不可靠，应该上 pseudo-bulk。

## 1. 聚类阶段

### 怎么知道分辨率太粗/太细
- **信号 - 太粗**：某个 cluster 的 marker 数量异常多（>50 且 logfc 都不大），说明 cluster 里混了多种细胞，每种贡献一点 marker。
- **信号 - 太细**：相邻 cluster 注释成完全相同的细胞类型，且 marker 重叠率高（>50%）。
- **排查**：跑 cluster tree 看 cluster 在不同分辨率下的稳定性，看哪个分辨率节点 cluster 数稳定（即"分得不碎也不合"）。
- **硬指标**：每个 cluster 的轮廓系数，<0.1 说明 cluster 之间区分度差（太粗）；>0.6 但 cluster 数极多可能太碎。

### 怎么知道批次效应主导了聚类
- **信号**：每个 cluster 几乎 100% 单一来源样本 → 强批次。
- **量化**：算每个 cluster 的"样本熵"，熵接近 0 说明纯单一来源 = 批次主导；健康状态是每个 cluster 样本混合。
- **排查动作**：画 cluster × sample 的堆叠柱状图，看是不是每个 cluster 都是单色块。

### 怎么知道聚类漏了关键 marker 基因
- **信号**：某种你"凭生物直觉该有"的细胞类型（如免疫细胞）在注释里完全消失。
- **排查**：拿该类型的经典 marker（如免疫的 LCK/CD3D）查它在哪些 cluster 表达，如果表达但没有对应 cluster → 聚类没分开，可能这个 marker 没进 HVG 池。
- **修复**：手动把这个 marker 加入 HVG 列表重聚类。

### 怎么知道被 UMAP 图骗了
- **信号**：UMAP 看着分得很开的两个 cluster，注释结果完全相同 → UMAP 距离≠真实相似度。
- **排查**：UMAP 只是可视化，判断 cluster 真实相似性看 PCA 空间距离或轮廓系数；两个 UMAP 上分开的 cluster 注释相同，不要急着说"注释错了"，可能本来就是一个类型的两个区域。

## 2. Marker 阶段

### 怎么知道管家基因混进 marker 了
- **信号**：top marker 列表里出现 RPL/RPS/MT-/HSP/Histone 基因；或注释结果全是"增殖细胞""代谢细胞"这种泛化标签。
- **排查**：DE 完后看 top 50 marker 的基因名前缀，过滤掉明显的管家基因再跑下游。
- **量化**：每个 marker 检查 pct1——pct1 >0.9 的"marker"几乎肯定是管家基因（到处都表达）。

### 怎么知道 marker 是假阳性（批次/质量驱动）
- **信号**：某 cluster 的 marker 在其他 cluster 也高表达（pct2 > 0.5），只是这个 cluster 细胞数少导致统计显著。
- **排查**：看每个 top marker 的 `pct1 - pct2`，<0.1 的直接丢——这种"marker"在所有 cluster 都表达，不是身份标签。
- **样本维度**：检查每个 marker 在该 cluster 内的样本分布，如果只在一个样本里高表达 → 批次 marker，不是细胞类型 marker。

### 怎么知道 marker 数量定错
- **信号 - 太少**：跨物种映射后命中率 <30%（marker 数太少，同源命中本来就不多）。
- **信号 - 太多**：注释结果里每个 cluster 命中 10+ 种细胞类型，第一和第二候选纠缠不清（噪声 marker 把候选搞散）。
- **排查**：看每个 cluster 的有效同源 hit 数，正常每个 cluster 应该有 10-50 个；<5 或 >100 都异常。

### 怎么知道 DE 对稀有细胞类型失效
- **信号**：占 1-5% 的稀有细胞类型注释特别模糊/unknown，但占 30%+ 的类型注释很清楚。
- **排查**：DE 结果里稀有类型的 marker logfc 普遍偏低（<1），p 值不显著——单细胞 DE 检验力不够。
- **修复**：稀有类型用 pseudo-bulk（按样本×cluster 聚合 counts）再跑 DE，比单细胞 DE 检验力强得多。

## 3. 跨物种映射阶段

### 怎么知道序列比对数据库物种选错
- **信号**：命中的相似度普遍很低（<30%），即使你用的是参考物种蛋白库。
- **排查**：取 10 个目标 marker，去公共序列比对工具（如 NCBI BLAST 网页版）手动跑，看 top hit 是不是落在你选的参考物种——如果手动 hit 到的物种和你用的库不同，库选错。
- **量化**：比对结果相似度中位数 <40%，亲缘太远，换近缘参考物种。

### 怎么知道一对多没处理好
- **信号**：一个 marker 命中 5+ 个参考物种基因，且这些基因标记 3+ 种完全不同的细胞类型 → 典型多拷贝噪声。
- **排查**：数每个 query 的 hit 数，画直方图——分布右尾长（很多 query 命中 5+ 条）说明一对多严重。
- **看注释**：某 cluster 注释为多种不相关类型（如 T 细胞+成纤维细胞+神经元），几乎肯定是某个多拷贝 marker 一次性命中多种类型。
- **修复**：改用"只取最佳 hit"模式重跑，看异常 cluster 是否消失。

### 怎么知道序列比对阈值定错
- **信号 - 太松**：命中率 >95%（几乎所有 marker 都命中），但很多命中相似度 <30% → 噪声 hit 一堆。
- **信号 - 太严**：命中率 <20%，大量 marker 无 hit。
- **排查**：看比对结果的相似度分布，找拐点——拐点前是高质量 hit，拐点后是噪声；阈值定在拐点。
- **对比验证**：把阈值放宽/收紧各跑一次，看注释结果稳定性——稳定说明阈值够用，剧烈变化说明阈值在临界点，需要谨慎。

### 怎么知道用了核酸做比对
- **信号**：跨物种命中相似度极低（<20%），即使亲缘很近。
- **排查**：看比对程序的运行模式，应该是蛋白比对，不是核酸比对。
- **快速检查**：取一个目标基因的蛋白序列和核酸序列分别比对，蛋白相似度应该显著高于核酸——如果核酸 hit 数远多于蛋白，可能在跑核酸比对。

### 怎么知道漏了 reciprocal best hit 验证
- **信号**：注释结果里某些 marker 投出的细胞类型明显不合理（如植物代谢基因注释成动物免疫细胞）。
- **排查**：取这个 marker 的参考物种 best hit，反向比对回目标物种，看 best hit 是不是原 marker——如果不是，这对"ortholog"是单向相似，不可信。
- **统计**：随机抽 50 个"ortholog"对做 RBB 验证，通过率 <80% 说明映射整体质量差，需要加 RBB 过滤。

### 怎么知道目标物种基因家族扩张未识别
- **信号**：目标物种某些基因在比对中命中参考物种同一基因多次（多个目标基因都 hit 到参考物种的同一个基因）→ 反向一对多。
- **排查**：数每个 subject（参考物种基因）被多少 query 命中，画直方图——某 subject 被命中 10+ 次说明目标物种这边是个扩张家族。
- **影响评估**：这个家族的注释结果整体降一档置信度；如果某个细胞类型主要靠这个家族的 marker 支撑，注释结论不稳。

## 4. 知识图谱/参考注释阶段

### 怎么知道 organ 选错
- **信号**：注释结果里出现明显不属于该 organ 的细胞类型（如叶片数据注释出"肝细胞"），或大量 unknown（organ 错导致 KG 过滤太严，大部分 marker 查不到）。
- **排查**：看 KG 查询结果——如果返回的细胞类型数很少（<5），organ 过滤太严，要么 organ 错要么该物种在该 organ 注释本身就少。
- **验证**：看同源基因里有多少比例在 KG 中查不到，>50% 说明 KG 在该 organ 几乎没数据，换 organ 或不过滤。

### 怎么知道参考物种图谱覆盖不全
- **信号**：所有参考物种都试过，unknown 率仍 >40%，且亲缘并不算远。
- **排查**：去参考物种的公开图谱查你这个 organ 有多少种已注释细胞类型——如果图谱本身只有 5 种，你注释出 3 种全是 unknown 是正常的，不是你的错。
- **多参考交叉**：换一个参考物种重跑，看 unknown 率是否下降——下降说明第一个参考物种图谱确实不全。

### 怎么知道细胞类型命名层级混乱
- **信号**：同一类型的细胞在不同 cluster 里被标了不同名字（"T cell" vs "T lymphocyte" vs "T-cell"），或合并统计时发现"有 50 种细胞类型"明显多于生物学实际。
- **排查**：列出所有注释出的 cell type 名字，肉眼检查重复/同义项。
- **修复**：建同义名映射表把同义名归一，或用 CL ontology ID 替代自由文本。

### 怎么知道物种特异细胞类型没被识别
- **信号**：unknown cluster 们的 marker 在所有参考物种都没命中，但 unknown 之间彼此的 marker 也不重叠 → 各自独立的"新"细胞类型，不是统一的"unknown"。
- **排查**：unknown cluster 之间做 DE，如果有显著差异，说明它们是不同类型（可能是物种特异），应分别标注"unknown type A/B"，而不是统称 unknown。

## 5. 注释判断阶段

### 怎么知道"弱命中多"压过了"强命中少"
- **信号**：某 cluster 被"弱命中很多"的类型胜出，胜过"强命中少数"的类型。
- **排查**：看该 cluster 每个 marker → 命中参考物种基因 → 命中细胞类型的明细，比较"按相似度强弱判断" vs "只数命中数"的结论差异——差异大说明在靠数量误导。
- **修复**：判断时相似度高的命中优先；强弱差异大时，强命中的一票胜过一堆弱命中。

### 怎么知道第一候选和第二候选势均力敌就下了结论
- **信号**：注释结果里某 cluster 最像的类型和第二像的类型差距很小，但 pipeline 报告了第一候选。
- **排查**：直接看每个 cluster 第一候选和第二候选的强度差距——纠缠不清的都该 refine，不该直接定。
- **量化统计**：数有多少个 cluster 第一和第二候选纠缠不清——>20% 说明整体注释不够 decisive，该批量 refine。

### 怎么知道标准定太严全 unknown
- **信号**：unknown 率 >50%。
- **排查**：看 unknown cluster 是"有候选但达不到标准（标准砍的）"还是"KG 无数据"——前者放宽标准，后者换 organ/参考物种。
- **快速测试**：把可信标准放宽一档，重跑看 unknown 率变化——降到 20% 以下说明标准是元凶，KG 不是。

### 怎么知道沿层级过度传播
- **信号**：所有 cluster 都被注释到很粗粒度（如全是"immune cell" "epithelial cell"），没有子类型。
- **排查**：看传播过程——如果每步保留的候选很少（1-2）且传播步数多（>3），说明弱信号一路传到顶层。
- **修复**：提高传播门槛（让弱信号不再往上传播），或切到不传播模式看粒度是否变细——变细说明传播过度。

## 6. 细化(refine)阶段

### 怎么知道 refine 触发条件不对
- **信号 - 触发过度**：所有 cluster 都触发 refine，包括第一候选碾压的 cluster → 浪费算力。
- **信号 - 触发不足**：注释结果明显有模糊 cluster（第一和第二候选纠缠不清）却没触发 refine。
- **排查**：列出所有 cluster 第一候选和第二候选的强度差距，看 refine 触发的 cluster 是不是那些纠缠不清的——只在纠缠不清时触发才合理。

### 怎么知道 refine 用错了 marker
- **信号**：refine 后子 cluster 之间 marker 几乎不重叠（共用父 cluster 的 marker 应该都还表达，但子 cluster 间 DE 几乎无差异）。
- **排查**：refine 时检查用的是父 cluster 全局 marker 还是子 cluster 局部 DE marker——前者分不开是必然。
- **修复**：refine 内部必须重做 DE（在父 cluster 范围内对比子 cluster），不能复用父级 marker。

### 怎么知道 Moran's I 阈值定错
- **信号 - 太严**：refine 后所有基因都被过滤掉，refine 结果为空。
- **信号 - 太松**：refine 后子 cluster 间仍无明显差异。
- **排查**：画 Moran's I 分布直方图，看阈值切在哪个位置——切在分布主体（不是尾部）就太严。
- **物种适配**：植物组织结构规则，I 值天然偏高，阈值要相对高；动物组织离散的，阈值要相对低。

### 怎么知道 refine 在小 cluster 上无意义
- **信号**：refine 后某 cluster 分成 3 个亚型，每个 10 个细胞。
- **排查**：refine 前看 cluster 细胞数，<100 的 cluster 直接跳过 refine——DE 检验力不够，分出来的是噪声。
- **汇报**：明确标注"细胞数不足，未细分"，而不是把噪声结果当亚型上报。

## 7. 验证与汇报阶段

### 怎么知道注释没独立证据支撑
- **信号**：注释报告只有"cluster 0 = T 细胞"标签，没有 marker 表达证据。
- **自查**：拿注释出的细胞类型，去查该类型的经典 marker（如 T 细胞的 CD3D/LCK）在你的 cluster 里是否真的高表达——不表达就是错的。
- **量化**：每个注释附带 top 3 canonical marker 的表达水平（pct1、mean expression）；不达标的标注"低置信度"。

### 怎么知道低置信度注释被当真用了
- **信号**：下游分析里所有 cluster 一视同仁，没有区分 high/low confidence。
- **自查**：明确给每个 cluster 标置信度（第一候选明显领先且 marker 数>15 = high；否则 medium/low），下游分析对 low 单独报告，不和 high 混合统计。

### 怎么知道没报告参考物种依赖性
- **信号**：注释结果只写"cluster 0 = T 细胞"，不写基于哪个参考物种。
- **自查**：注释元数据必须包含参考物种、KG 版本、比对阈值——别人换参考物种复现不出同样的结果，可复现性就破了。

## 总体自检清单（每次跑完必做）

跑完 pipeline 后花 10 分钟做这 6 项检查，能抓住 80% 的坑：

1. **看命中率**：每个 cluster 的有效同源 hit 数，应在 10-50 之间。
2. **看 unknown 率**：unknown cluster 比例 >30% 就要查（阈值/organ/参考物种覆盖）。
3. **看第一候选和第二候选的差距**：纠缠不清的 cluster 占比 >20% 就该 refine。
4. **抽查 5 个注释**：随机 5 个 cluster，查其注释类型的 canonical marker 是否真在该 cluster 高表达。
5. **看批次混合**：每个 cluster 的样本来源是否混合（不是单一来源）。
6. **看元数据**：注释结果是否记录了参考物种、KG 版本、阈值——没有就补上，否则不可复现。

这 6 项任何一项异常，回头看对应阶段的详细排查动作。

## 速查表：症状 → 第一时间看的中间产物

| 异常症状 | 第一时间查 | 正常应该看到 |
|---|---|---|
| 注释全 unknown | 同源命中表 + KG 查询结果 | 每个 marker 都有有效同源命中；KG 返回非空 |
| 注释全同一种类型 | top marker 列表 | 不该全是管家基因 |
| 注释粒度太粗 | 传播过程日志 | 步数 ≤3，保留候选数合理 |
| 注释粒度太细 | cluster 数 + 分辨率 | 数和生物学预期一致 |
| 少数 cluster 离谱 | 该 cluster marker 的 pct1/pct2 | pct1 - pct2 >0.25 |
| 重跑结果不变 | 是否复用了旧中间结果 | 改了参数应该重跑该步骤，不是复用 |
| 跑几天没结果 | 同源映射进度 + KG 响应 | 同源映射应在几小时内完成；KG 应该返回数据 |
